# Basic Data Cleaning

## 📌 Project Overview

This project demonstrates basic data cleaning techniques using Python and Pandas. A real-world dataset is cleaned by handling missing values, removing duplicate records, and correcting data types.

## 🎯 Objective

The objective of this project is to understand and apply fundamental data-cleaning techniques in a practical workflow.

## 🛠️ Tools Used

- Python
- Pandas
- Jupyter Notebook

## 📊 Data Cleaning Steps

### 1. Data Inspection
The dataset was inspected to understand its structure, columns, data types, and overall quality.

### 2. Handling Missing Values
Missing values were identified using Pandas. Appropriate methods such as filling missing values or removing unnecessary missing records were used.

### 3. Removing Duplicates
Duplicate records were checked and removed to ensure the dataset contains unique and reliable data.

### 4. Correcting Data Types
Data types of columns were checked and corrected where necessary to ensure proper data analysis.
